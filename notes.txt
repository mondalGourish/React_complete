*Real DOM vs Virtual DOM
the Real DOM represents the actual UI structure rendered on screen by the browser, while the Virtual DOM is a lightweight, in-memory JavaScript copy used by libraries like React to optimize performance.

Instead of rewriting the actual browser page layout every time a state change occurs, React uses a step-by-step optimization cycle:

^ State Update: A user triggers an action (e.g., clicking a button) that updates state.
^ New Virtual Tree: React generates a brand new Virtual DOM tree representing the updated look of the interface.
^ Diffing: React compares this new Virtual DOM with a snapshot of the old Virtual DOM to pinpoint exactly what changed.
^ Reconciliation: A specialized synchronizing tool called ReactDOM applies only the necessary changes to the Real DOM

*Hooks in react(magical function which can perform some task)
useState    useEffect   useRef  useMemo useCallback useContext  useReducer

useState -> manages state(manages any change in state)(basic state management)

useEffect -> also make changes in the website but without disturbing the main function going on, it silently does it works(used in api call, dom manipulation, event listener)

useRef -> it helps to select the dom elements

useContext -> helps to manage context api ,basically some is present globally and helps it to access them(global state management)

useReducer -> helps to handle complex logic (complex global state management)

useMemo,useCallback -> helps in optimization,memoization (helps to reduce re-rendering by optimization)
